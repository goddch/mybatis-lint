## 0.2.0

## 0.1.9

- 定義へ移動で、mapper XML と Java の間を移動できるようにしました

- 解析エンジンを起動したままにして、チェックを速くしました
- 修正：移動先を探すときに、正規表現の特殊文字を正しく扱うようにしました

## 0.1.8

## 0.1.7

- INSERT の値の横に列名を表示し、列と値の数を確認するようにしました
- 打ち間違いに正しい名前の候補を出し、クイックフィックスで直せるようにしました
- 動的 SQL で残った `AND` / `OR` / カンマと、空になる句を報告するようにしました

## 0.1.6

## 0.1.5

- `<foreach>` の item のプロパティと、ファイルをまたいだ statement ID の重複を確認するようにしました
